This assignment demonstrates different ways to create and manage arrays (or list-like structures) in Python** and C++, based on how memory is allocated. It includes simple examples of four common types of array allocation methods.

 Types of Array Allocation Explained

1. Fixed Stack Dynamic

   The array has a fixed size, defined in the code. It's stored in stack memory.

2. Stack Dynamic

   The array size is decided during the program's execution (at runtime), but it still uses stack memory.

3. Fixed Heap Dynamic

   The array is stored in heap memory, and its size is fixed when the object is created.

4. Heap Dynamic

   The array is stored in heap memory and can grow or shrink while the program runs.
